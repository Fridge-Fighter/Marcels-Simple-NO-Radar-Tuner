# Marcels-Simple-NO-Radar-Tuner
A simple nuclear option mod that enables the player to freely configure the radar variables literally on the fly. Adjust range, clutter factor, doppler factor and stealth multiplier from the F1 menu. Fine tune your gameplay experience however you like.

This mod is 100% vibecoded using Grok and I feel 0% shame. I´m a results oriented type of guy and shit´s free yo!
